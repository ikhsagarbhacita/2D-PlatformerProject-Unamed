# 2D-PlatformerProject-Unamed
A 2D Adventure-Platformer developed using Unity 6 and C#. Built upon the foundations of "The Complete Guide to Unity 2D : Platformer Development" course on Udemy, this project demonstrates core platformer mechanics, custom player controls, dynamic camera management, and modular UI systems built for my game development portfolio.

## Project Overview
This repository showcases practical game programming concepts, focusing on clean C# code structure, performance optimization, and responsive player controls. Initially created through hands-on learning, it serves as a foundation for scalable game architecture ready for production workflows.

# Key Features
- Custom Character Controller: Fluid player movement including running, double jumping, flying mechanics, and wall slide interactions.
- Combat & Hazard Mechanics: Enemy AI behaviors, dynamic environmental hazards/traps, and health management systems.
- Dynamic Camera System: Smooth camera transitions and framing powered by Cinemachine.
- UI & State Management: Responsive event-driven UI systems for health bars, score tracking, and game state overlays.

# Tech Stack & Tools
- Game Engine: Unity 6
- Language: C#
- Input Handling: Unity New Input System
- Camera System: Cinemachine
- Version Control: Git & GitHub

# Future Roadmap & Next Development
This project is actively being expanded with the following planned features:
- Local Split-Screen Multiplayer Implementation: Adding 2-player local split-screen co-op functionality using Unity's New Input System (supporting simultaneous Keyboard & Gamepad controls).
- Expanded Level Design: Designing new levels with increased verticality and progressive difficulty tailored for both single-player and co-op play.
- New Enemy Types & AI: Integrating diverse enemy AI behaviors and attack patterns.
- Environmental Traps & Hazards: Implementing complex hazard mechanics (spikes, falling platforms, saws) to deepen level challenges.
- Architecture & UI Refinement: Continuously updating game architecture and polishing UI state managers for an improved player experience.
